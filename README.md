# Intelligente Messsysteme: Thermal Flow Sensor

Group project for VA4 Intelligente Messsysteme (HTW Berlin, 2. Semester).

We build the **thermal flow module** for a modular sensor platform: a flow meter for 50 to 200 ml/h in a glass capillary (0.5 mm inner / 1.5 mm outer diameter). The platform is made of stackable round PCB discs. The C4D and optical sensors are built by other groups, and everything is combined in an FPGA.
